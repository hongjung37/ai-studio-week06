## 1. 과업 정의

- 선택: (나) 리뷰 분류
 
- 분류 항목과 긴급도 기준: [배송/품질/가격/서비스/기타]로 분류하며 부정적인 부분과 가장 가까운 카테고리로 분류한다. 또한  리뷰가 부정적이고 , 부정적인 요소에 대한 대응 필요 속도에 의해 긴급도가 결정된다.

   - 구체적인 평가 기준 
     -  1: 개선할 점이 없거나 단순 칭찬, 만족, 일반 의견일 경우
     -  2: 개선할 점이 있으나 대응이 시급하지는 않은 경우 (경미한 불만, 개선요청 등)
     -  3: 개선할 점이 있고 대응이 시급한 경우 (심각한 하자, 파손등)
    
- 출력 형식: {"type": ..., "urgency": ...}

## 3. 프롬프트 전문

### Zero-shot
```
[분류 유형]
- 배송, 품질, 가격, 서비스, 기타 중 택 1

[분류 기준]
부정적인 부분에 초점을 맞춰 분류한다. 없을 경우 좋은 부분.

[긴급도 기준]
- 1 - 개선할 점이 없거나 단순 칭찬, 만족, 일반 의견일 경우
- 2 - 개선할 점이 있으나 대응이 시급하지는 않은 경우 (경미한 불만, 개선요청 등)
- 3 - 개선할 점이 있고 대응이 시급한 경우 (심각한 하자, 파손등)

[출력 형식]
반드시 다른 설명이나 추가 문장없이 JSON 형식으로만 응답.
{"type": "유형", "urgency": 숫자}

[고객 리뷰]
{INPUT_TEXT}
```
### Few-shot
```
다음 고객 리뷰를 읽고 분류 유형과 긴급도를 판정해주세요.

[분류 유형]
- 배송, 품질, 가격, 서비스, 기타 중 택 1

[분류 기준]
부정적인 부분에 초점을 맞춰 분류한다. 없을 경우 좋은 부분.

[긴급도 기준]
- 1 - 개선할 점이 없거나 단순 칭찬, 만족, 일반 의견일 경우
- 2 - 개선할 점이 있으나 대응이 시급하지는 않은 경우 (경미한 불만, 개선요청 등)
- 3 - 개선할 점이 있고 대응이 시급한 경우 (심각한 하자, 파손등)

[출력 형식]
반드시 다른 설명이나 추가 문장없이 JSON 형식으로만 응답.
{"type": "유형", "urgency": 숫자}


[예시]
리뷰: 주문한 지 하루 만에 도착해서 포장도 꼼꼼하게 잘 왔습니다.
출력: {"type": "배송", "urgency": 1}

리뷰: 디자인은 예쁜데 마감이 너무 조잡하네요.
출력: {"type": "품질", "urgency": 2}

리뷰: 구성품이 판매 페이지랑 일치 하지 않네요.
출력: {"type": "품질", "urgency": 3}

리뷰: 배송 기사님이 던지고 가서 박스랑 내용물이 다 찌그러졌는데, 고객센터는 전화도 안 받네요.
출력: {"type": "서비스", "urgency": 3}

리뷰: 이 가격에 이 퀄리티라니 사장님이 미쳤네요.
출력: {"type": "가격", "urgency": 1}


[고객 리뷰]
{INPUT_TEXT}
```
### CoT
```
다음 고객 리뷰를 읽고 단계별로 추론한 뒤, 최종 결과를 마지막 줄에 JSON으로 출력해주세요.

[분류 유형]
- 배송, 품질, 가격, 서비스, 기타 중 택 1

[분류 기준]
부정적인 부분에 초점을 맞춰 분류한다. 없을 경우 좋은 부분.

[긴급도 기준]
- 1 - 개선할 점이 없거나 단순 칭찬, 만족, 일반 의견일 경우
- 2 - 개선할 점이 있으나 대응이 시급하지는 않은 경우 (경미한 불만, 개선요청 등)
- 3 - 개선할 점이 있고 대응이 시급한 경우 (심각한 하자, 파손 등)

[추론 절차]
반드시 다음 단계를 순서대로 거쳐 분석을 작성하세요.
1단계 (핵심 주제 분석): 리뷰에서 언급된 주요 내용 중 부정적인 요소(없다면 긍정적 요소)가 무엇인지 파악한다.
2단계 (유형 판정): 파악한 요소를 바탕으로 [배송, 품질, 가격, 서비스, 기타] 중 어디에 해당하는지 판정한다.
3단계 (긴급도 판정): 불만의 심각성과 즉각적인 조치 필요성을 고려하여 [1, 2, 3] 중 하나의 긴급도를 결정한다.

[출력 형식]
위 1~3단계 추론 과정을 먼저 작성하고,
반드시 응답의 맨 마지막 줄에는 아래 JSON 형식만 단독으로 출력하세요.
{"type": "유형", "urgency": 숫자}

[고객 리뷰]
{INPUT_TEXT}
```
